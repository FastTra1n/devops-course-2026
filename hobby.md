# Мой пет-проект

Идея: десктопное приложение для учёта, каталогизации и организации личной библиотеки компьютерных игр
Стек: 
- C# (.NET 10.0)
- EntityFramework Core (v10.0.8)
- WPF 

Цель: научиться грамотно выстраивать архитектуру приложения, используя различные паттерны проектирования, и подтянуть навыки работы с языком программирования C#

Дорожная карта разработки:
- [x] Подготовить среду для разработки приложения
- [x] Спроектировать базу данных для хранения информации об играх
- [x] Определить основные сущности и настроить связь с БД
- [x] Сделать прототип интерфейса приложения (разметить структуру)
- [x] Реализовать логику получения, редактирования и удаления игр, тегов и коллекций
- [x] Установить связь Model-уровня и View-уровня через промежуточный этап, согласно паттерну MVVM.
- [x] Реализовать раздел с добавлением, редактированием и удалением игр
- [x] Реализовать базовую навигацию между разделами приложения
- [ ] Реализовать раздел с добавлением, редактированием и удалением тегов
- [ ] Реализовать раздел с добавлением, редактированием и удалением коллекций
- [ ] Поменять дизайн приложения (от чернового варианта к итоговому)
- [ ] До конца реализовать обработку исключительных случаев в программе
- [ ] Добавить систему логирования критических ошибок/предупреждений при работе с программой
- [ ] Реализовать возможность установки изображения для игры с помощью прямой ссылки на изображение
