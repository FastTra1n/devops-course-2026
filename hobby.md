# Мой пет-проект

Идея: десктопное приложение для учёта, каталогизации и организации личной библиотеки компьютерных игр
Стек: C# + EF Core + WPF
Цель: научиться грамотно выстраивать архитектуру приложения, используя различные паттерны проектирования, и подтянуть навыки работы с языком программирования C#
