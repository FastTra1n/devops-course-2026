Плюсы: 
1. Интеграция с GitLens позволяет увидеть кто, когда и в каком коммите изменил код на выбранной строчке прямо в конце текущей строки.
2. VS Code избавляет от запоминания рутинных команд (к примеру, git commit), предлагая удобный интерфейс для взаимодействия.
3. При возникновении конфликта, во время merge, VS Code подсвечивает конфликтующие строки разными цветами и предлагает удобные кнопки прямо над кодом.

Минусы:
1. Узкоспециализированные или опасные команды могут быть не доступны в интерфейсе VS Code. Более того, в терминале можно более точечно контролировать вводимые команды с помощью флагов.
